# はじめに
プログラムワークショップⅣの4つ目の管理用です

# 結果画像

![第4回の結果](result.png)

左から順に
- 左：Unlit Shader Graphで作ったランバート拡散反射（Main Light Direction と Normal Vector(World) の内積 × -1 → Maximum(0) → Albedo を乗算）
- 中央：追加で試したハーフランバート（ランバートの値を ×0.5+0.5 して 0〜1 に収める）
- 右：Lit Shader Graph（Albedo を Base Color につないだだけ）

- 工夫した点：ランバートとの比較用にハーフランバートの球を追加した。ランバートは光が当たらない側が真っ黒になるが、ハーフランバートは裏側まで明るさがなだらかに変化するので、影の部分がつぶれにくい。Litは環境光やスペキュラ、自己影が入るので、自作の2つと比べると影側も少し明るく、ハイライトも出ている。
- Directional Light を横からやや手前に当たる角度（X:25, Y:-80）にして、明暗の境目が見やすいようにした。床を置いたので、Unlitの球も影を落とす（受けはしない）ことがわかる。
